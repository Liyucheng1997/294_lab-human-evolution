# 人类的进化 · 3D 互动之旅

从 38 亿年前的早期生命证据到智人，通过 15 个可交互的 Three.js 场景展示生命演化主干上的关键节点。

## 特性

- 15 个程序化 3D 生物与古环境场景
- 拖拽旋转、滚轮缩放、键盘导航与自动播放
- 可点击的解剖结构热点与线框视图
- 对数时间轴、地球年压缩日历和人族脑容量对比
- 可交互的生命谱系树
- 移动端响应式布局
- 科学证据、不确定性说明与权威参考来源

## 本地运行

```bash
npm install
npm run dev
```

打开 Vite 输出的本地地址即可。

## 构建

```bash
npm run build
```

## 技术栈

- TypeScript
- Three.js
- Vite
- Cloudflare Workers / OpenAI Sites

## 科学范围

页面展示的是经科学简化的一条演化主干路径，不是通往人类的线性阶梯。3D 生物为了解释特征而制作的概念复原，不是按比例的化石扫描。早期生命、真核细胞起源和部分人族分类仍在持续研究中。
